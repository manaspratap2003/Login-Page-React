# Login-Page-React

A simple React login application with form validation and user details display.

## Features

- Login Form : Collects user name, email, and password
- User Details : Displays entered information after successful login
- React Router : Client-side routing between login and details pages
- Tailwind CSS : Modern, responsive styling

## Tech Stack

| Technology       | Version |
|------------------|---------|
| React            | 19.2.5  |
| Vite             | 8.0.10  |
| React Router DOM | 7.14.2  |
| Tailwind CSS     | 4.2.4   |

## Installation

    npm install

## Running the Project

    npm run dev

The app will be available at http://localhost:5173

## Project Structure

    src/
    +-- App.jsx        Main app with routing
    +-- LoginForm.jsx  Login form component
    +-- Details.jsx    User details display component
    +-- index.css      Global styles
    +-- main.jsx       Entry point
